💻

การพัฒนาระบบซอฟต์แวร์

  • วิเคราะห์ความต้องการ ออกแบบ และพัฒนาซอฟต์แวร์สำหรับภาครัฐและเอกชน
  • พัฒนา REST API เชื่อมต่อระบบและ Mobile Application
  • ทดสอบระบบ (UAT) จัดทำเอกสาร อบรมผู้ใช้งาน และนำระบบขึ้น Production
🏢

การพัฒนาระบบ ERP & Workflow

  • พัฒนาระบบ ERP ครอบคลุมงานจัดซื้อ (PR/PO) ตรวจรับสินค้า และคลังสินค้า
  • พัฒนาระบบการเงิน บุคคล จองรถ บริหารโครงการ และจัดการสิทธิ์ผู้ใช้งาน
  • พัฒนา Approval Workflow เพื่อเพิ่มความรวดเร็วในการอนุมัติเอกสาร
🔗

การเชื่อมต่อระบบ

  • ออกแบบและพัฒนา Backend API เพื่อแลกเปลี่ยนข้อมูลกับระบบภายนอก
  • เชื่อมต่อระบบซอฟต์แวร์และ Mobile Application อย่างมีประสิทธิภาพ
🗄️

การจัดการฐานข้อมูล

  • ใช้ SQL จัดการและแก้ไขข้อมูล พร้อมวิเคราะห์ปัญหาฐานข้อมูลและ System Log
  • พัฒนาระบบจัดการสิทธิ์และนำเข้าข้อมูล พร้อมประเมินผลกระทบก่อนปรับปรุง
⚙️

การจัดการ Source Code & AI

  • ตรวจสอบและทดสอบ Source Code เมื่อมีการเปลี่ยนแปลงเวอร์ชัน
  • ใช้ Claude AI, Devin, ChatGPT และ Gemini ช่วย Code Review และวิเคราะห์โค้ด
  • วิเคราะห์ Root Cause Analysis และแก้ไขปัญหาก่อนขึ้น Production
🤝

การดูแลระบบและประสานงาน

  • ดูแลและสนับสนุนการใช้งานระบบซอฟต์แวร์ของลูกค้า
  • ประสานงานกับลูกค้าและทีมพัฒนา เพื่อติดตามและแก้ไขปัญหา
  • เตรียมความพร้อมสำหรับโครงการใหม่ของหน่วยงานภาครัฐ
